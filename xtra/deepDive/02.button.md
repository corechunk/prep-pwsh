
# 📂 File 02 — Button (Complete Interaction Surface)

## THEORY

The Button is one of the most powerful interactive controls in WPF.  
It is not just a clickable element — it participates in:

- Routed event system (bubbling & tunneling)
- Keyboard interaction
- Focus management
- Visual state changes
- Styling & templating
- Content hosting (it can contain ANY UI element)
- Command binding
- Animation triggers

In WPF, a Button is a **ContentControl**, meaning:
It can host text, images, panels, or even full layouts inside it.

---

# SECTION 1 — BASIC BUTTON

## Minimal Working Example (PS 5.1 + PS 7.1)

```pwsh
Add-Type -AssemblyName PresentationFramework
Add-Type -AssemblyName PresentationCore
Add-Type -AssemblyName WindowsBase

[xml]$xaml = @"
<Window
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    Title="Button Example"
    Width="400"
    Height="250"
    WindowStartupLocation="CenterScreen">

    <Grid>
        <Button
            Name="btnMain"
            Content="Click Me"
            Width="120"
            Height="40"
            HorizontalAlignment="Center"
            VerticalAlignment="Center"/>
    </Grid>

</Window>
"@

$reader = New-Object System.Xml.XmlNodeReader $xaml
$window = [Windows.Markup.XamlReader]::Load($reader)

$btn = $window.FindName("btnMain")

$btn.Add_Click({
    [System.Windows.MessageBox]::Show("Button Clicked")
})

$window.ShowDialog() | Out-Null
```

# SECTION 2 — ALL MAJOR BUTTON EVENTS

WPF uses a **Routed Event System**.

Events travel through the visual tree in two modes:

- Tunneling (Preview*)
- Bubbling (normal events)

---

## Mouse Events

```pwsh
$btn.Add_MouseEnter({ Write-Host "Mouse Enter" })
$btn.Add_MouseLeave({ Write-Host "Mouse Leave" })
$btn.Add_MouseMove({ Write-Host "Mouse Moving" })
$btn.Add_MouseDown({ Write-Host "Mouse Down" })
$btn.Add_MouseUp({ Write-Host "Mouse Up" })
$btn.Add_MouseWheel({ Write-Host "Mouse Wheel" })

# Tunneling versions
$btn.Add_PreviewMouseDown({ Write-Host "Preview Mouse Down" })
$btn.Add_PreviewMouseUp({ Write-Host "Preview Mouse Up" })
```

---

## Detect Double Click

```pwsh
$btn.Add_MouseDown({
    if ($_.ClickCount -eq 2) {
        Write-Host "Double Clicked"
    }
})
```

---

## Keyboard Events

```pwsh
$btn.Add_KeyDown({
    if ($_.Key -eq "Enter") {
        Write-Host "Enter Pressed"
    }
})

$btn.Add_KeyUp({
    Write-Host "Key Released"
})

$btn.Add_TextInput({
    Write-Host "Text Input"
})
```

---

## Focus Events

```pwsh
$btn.Add_GotFocus({ Write-Host "Button Focused" })
$btn.Add_LostFocus({ Write-Host "Button Lost Focus" })
```

---

## Lifecycle Events

```pwsh
$btn.Add_Loaded({ Write-Host "Button Loaded" })
$btn.Add_IsEnabledChanged({ Write-Host "Enabled State Changed" })
```

# SECTION 3 — STYLING A BUTTON

Buttons support deep styling via properties or styles.

---

## Direct Property Styling

```pwsh
$btn.Background = "DarkBlue"
$btn.Foreground = "White"
$btn.FontSize = 16
$btn.FontWeight = "Bold"
$btn.BorderBrush = "Black"
$btn.BorderThickness = 2
```

---

## XAML Styling

```pwsh
<Button
    Content="Styled"
    Background="#2C3E50"
    Foreground="White"
    FontSize="16"
    FontWeight="Bold"
    BorderBrush="#34495E"
    BorderThickness="2"/>
```

# SECTION 4 — HOVER EFFECT WITHOUT CODE

Using Triggers (recommended over MouseEnter events).

```xml
<Button Content="Hover Me">
    <Button.Style>
        <Style TargetType="Button">
            <Setter Property="Background" Value="Gray"/>
            <Style.Triggers>
                <Trigger Property="IsMouseOver" Value="True">
                    <Setter Property="Background" Value="Blue"/>
                </Trigger>
                <Trigger Property="IsPressed" Value="True">
                    <Setter Property="Background" Value="DarkBlue"/>
                </Trigger>
            </Style.Triggers>
        </Style>
    </Button.Style>
</Button>
```

Triggers are declarative and more maintainable.

# SECTION 5 — BUTTON WITH IMAGE + TEXT

Since Button is ContentControl, it can host layout.

```xml
<Button Width="160" Height="50">
    <StackPanel Orientation="Horizontal">
        <Image Source="icon.png" Width="20" Height="20" Margin="0,0,8,0"/>
        <TextBlock Text="Open File" VerticalAlignment="Center"/>
    </StackPanel>
</Button>
```

# SECTION 6 — DISABLE / ENABLE BUTTON

```pwsh
$btn.IsEnabled = $false
```

# SECTION 7 — TOOLTIPS

Simple tooltip:

```xml
<Button Content="Hover Me" ToolTip="This is a tooltip"/>
```

Complex tooltip:

```xml
<Button Content="Hover Me">
    <Button.ToolTip>
        <StackPanel>
            <TextBlock Text="Information"/>
            <Image Source="icon.png" Width="20"/>
        </StackPanel>
    </Button.ToolTip>
</Button>
```

# SECTION 8 — BUTTON AS DEFAULT ACTION

If you want Enter key to trigger it:

```xml
<Button Content="Submit" IsDefault="True"/>
```

Cancel button (Esc key):

```xml
<Button Content="Cancel" IsCancel="True"/>
```

---

# SECTION 9 — ANIMATED BUTTON (Opacity Example)

```xml
<Button Content="Fade">
    <Button.Triggers>
        <EventTrigger RoutedEvent="MouseEnter">
            <BeginStoryboard>
                <Storyboard>
                    <DoubleAnimation
                        Storyboard.TargetProperty="Opacity"
                        To="0.5"
                        Duration="0:0:0.2"/>
                </Storyboard>
            </BeginStoryboard>
        </EventTrigger>
    </Button.Triggers>
</Button>
```

---

# SECTION 10 — CUSTOM TEMPLATE (ADVANCED)

You can completely redesign button appearance using ControlTemplate.

Example skeleton:

```xml
<Button Content="Custom">
    <Button.Template>
        <ControlTemplate TargetType="Button">
            <Border Background="DarkSlateBlue" CornerRadius="10">
                <ContentPresenter HorizontalAlignment="Center"
                                  VerticalAlignment="Center"/>
            </Border>
        </ControlTemplate>
    </Button.Template>
</Button>
```

This replaces the default Windows button look entirely.

---

# SECTION 11 — RUNTIME CONTENT CHANGE

```pwsh
$btn.Content = "New Text"
```

Or replace with layout:

```pwsh
$stack = New-Object System.Windows.Controls.StackPanel
$text = New-Object System.Windows.Controls.TextBlock
$text.Text = "Dynamic"
$stack.Children.Add($text)
$btn.Content = $stack
```

# SUMMARY

A Button in WPF is:

- A ContentControl
- A RoutedEvent participant
- A Style-driven visual element
- A Keyboard-interactive control
- Animation-capable
- Fully template-replaceable

It is far more powerful than a simple click handler.
