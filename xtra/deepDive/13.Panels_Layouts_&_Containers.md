# 📂 File 13 — Panels, Layouts & Containers in WPF + PowerShell

---

# THEORY

WPF provides multiple layout containers (panels) that help position and organize UI elements. Understanding them is key to building responsive UIs.

**Key Panels:**

1. **StackPanel** — Stacks elements horizontally or vertically.
2. **Grid** — Flexible row/column-based layout.
3. **DockPanel** — Dock children to edges.
4. **WrapPanel** — Wraps elements to next line/column.
5. **Canvas** — Absolute positioning.
6. **ScrollViewer** — Adds scrolling to content.
7. **TabControl** — Tabs for multiple pages.
8. **Expander** — Collapsible/expandable content.

---

# SECTION 1 — STACKPANEL

```pwsh
$stack = New-Object System.Windows.Controls.StackPanel
$stack.Orientation = "Vertical"
$stack.Margin = 10

for ($i=1; $i -le 5; $i++) {
    $btn = New-Object System.Windows.Controls.Button
    $btn.Content = "Button $i"
    $btn.Margin = [System.Windows.Thickness]::new(5)
    $stack.Children.Add($btn)
}

$window.Content = $stack
```

---

# SECTION 2 — GRID

```pwsh
$grid = New-Object System.Windows.Controls.Grid

# Define rows
for ($i=0; $i -lt 3; $i++) {
    $row = New-Object System.Windows.Controls.RowDefinition
    $row.Height = [System.Windows.GridLength]::Auto
    $grid.RowDefinitions.Add($row)
}

# Define columns
for ($i=0; $i -lt 2; $i++) {
    $col = New-Object System.Windows.Controls.ColumnDefinition
    $col.Width = [System.Windows.GridLength]::Auto
    $grid.ColumnDefinitions.Add($col)
}

# Add buttons in cells
for ($r=0; $r -lt 3; $r++) {
    for ($c=0; $c -lt 2; $c++) {
        $btn = New-Object System.Windows.Controls.Button
        $btn.Content = "R$r C$c"
        [System.Windows.Controls.Grid]::SetRow($btn,$r)
        [System.Windows.Controls.Grid]::SetColumn($btn,$c)
        $grid.Children.Add($btn)
    }
}

$window.Content = $grid
```

# SECTION 3 — DOCKPANEL

```pwsh
$dock = New-Object System.Windows.Controls.DockPanel
$dock.LastChildFill = $true

$top = New-Object System.Windows.Controls.Button
$top.Content = "Top Dock"
[System.Windows.Controls.DockPanel]::SetDock($top,"Top")
$dock.Children.Add($top)

$left = New-Object System.Windows.Controls.Button
$left.Content = "Left Dock"
[System.Windows.Controls.DockPanel]::SetDock($left,"Left")
$dock.Children.Add($left)

$center = New-Object System.Windows.Controls.TextBox
$center.Text = "Center fills remaining"
$dock.Children.Add($center)

$window.Content = $dock
```

# SECTION 5 — CANVAS

# SECTION 6 — SCROLLVIEWER

```pwsh
$scroll = New-Object System.Windows.Controls.ScrollViewer
$scroll.Width = 200
$scroll.Height = 100

$stack = New-Object System.Windows.Controls.StackPanel
for ($i=1; $i -le 20; $i++) {
    $txt = New-Object System.Windows.Controls.TextBlock
    $txt.Text = "Item $i"
    $stack.Children.Add($txt)
}

$scroll.Content = $stack
$window.Content = $scroll
```

# SECTION 7 — TABCONTROL

```pwsh
$tabs = New-Object System.Windows.Controls.TabControl
$tabs.Width = 300
$tabs.Height = 200

for ($i=1; $i -le 3; $i++) {
    $tab = New-Object System.Windows.Controls.TabItem
    $tab.Header = "Tab $i"

    $txt = New-Object System.Windows.Controls.TextBlock
    $txt.Text = "Content of Tab $i"
    $txt.Margin = 10

    $tab.Content = $txt
    $tabs.Items.Add($tab)
}

$window.Content = $tabs
```

# SECTION 9 — NESTED LAYOUTS

```pwsh
$grid = New-Object System.Windows.Controls.Grid
$row = New-Object System.Windows.Controls.RowDefinition
$row.Height = [System.Windows.GridLength]::Auto
$grid.RowDefinitions.Add($row)

$stack = New-Object System.Windows.Controls.StackPanel
$stack.Orientation = "Horizontal"
for ($i=1; $i -le 3; $i++) {
    $btn = New-Object System.Windows.Controls.Button
    $btn.Content = "Btn $i"
    $stack.Children.Add($btn)
}

[System.Windows.Controls.Grid]::SetRow($stack,0)
$grid.Children.Add($stack)

$scroll = New-Object System.Windows.Controls.ScrollViewer
$scroll.Width = 200
$scroll.Height = 100

$innerStack = New-Object System.Windows.Controls.StackPanel
for ($i=1; $i -le 10; $i++) {
    $txt = New-Object System.Windows.Controls.TextBlock
    $txt.Text = "Item $i"
    $innerStack.Children.Add($txt)
}
$scroll.Content = $innerStack
[System.Windows.Controls.Grid]::SetRow($scroll,1)
$grid.RowDefinitions.Add((New-Object System.Windows.Controls.RowDefinition))
$grid.Children.Add($scroll)

$window.Content = $grid
```

# SECTION 10 — SUMMARY

- StackPanel → simple linear layout
- Grid → flexible rows/columns
- DockPanel → dock elements to edges
- WrapPanel → wrap elements when space runs out
- Canvas → absolute positioning
- ScrollViewer → scrollable content
- TabControl → multiple pages
- Expander → collapsible content
- Nested layouts → combine panels for complex UI
