# 📂 File 10 — Layouts & Advanced Controls in WPF + PowerShell

---

# THEORY

Layouts in WPF determine how child elements are arranged in a parent container. PowerShell can fully manipulate these controls. Key containers:

1. **StackPanel** — Arranges children vertically or horizontally.
2. **DockPanel** — Dock children to Left, Right, Top, Bottom; last child fills remaining space.
3. **WrapPanel** — Wraps children to next line when space runs out.
4. **Grid** — Most powerful, supports rows, columns, spanning.
5. **ScrollViewer** — Enables scrolling for overflowing content.
6. **TabControl** — Multiple tabs with different content per tab.
7. **TreeView** — Hierarchical view of items.
8. **DataGrid** — Table-like control, supports sorting, editing, binding.

---

# SECTION 1 — STACKPANEL

```pwsh
$stack = New-Object System.Windows.Controls.StackPanel
$stack.Orientation = "Vertical"  # or "Horizontal"

$btn1 = New-Object System.Windows.Controls.Button
$btn1.Content = "Button 1"
$stack.Children.Add($btn1)

$btn2 = New-Object System.Windows.Controls.Button
$btn2.Content = "Button 2"
$stack.Children.Add($btn2)

$window.Content = $stack
```

- **Notes:** StackPanel auto-stacks controls; use `Margin` for spacing.

---

# SECTION 2 — DOCKPANEL

```pwsh
$dock = New-Object System.Windows.Controls.DockPanel

$btnTop = New-Object System.Windows.Controls.Button
$btnTop.Content = "Top Dock"
[System.Windows.Controls.DockPanel]::SetDock($btnTop, "Top")
$dock.Children.Add($btnTop)

$btnLeft = New-Object System.Windows.Controls.Button
$btnLeft.Content = "Left Dock"
[System.Windows.Controls.DockPanel]::SetDock($btnLeft, "Left")
$dock.Children.Add($btnLeft)

$mainContent = New-Object System.Windows.Controls.TextBlock
$mainContent.Text = "Fills remaining space"
$dock.Children.Add($mainContent)

$window.Content = $dock
```

---

# SECTION 3 — WRAPPANEL

```pwsh
$wrap = New-Object System.Windows.Controls.WrapPanel
$wrap.Orientation = "Horizontal"

for ($i=1; $i -le 10; $i++) {
    $btn = New-Object System.Windows.Controls.Button
    $btn.Content = "Btn $i"
    $btn.Width = 80
    $btn.Height = 30
    $btn.Margin = [System.Windows.Thickness]::new(5)
    $wrap.Children.Add($btn)
}

$window.Content = $wrap
```

- **Notes:** WrapPanel automatically moves controls to next line when space runs out.

---

# SECTION 4 — SCROLLVIEWER

```pwsh
$scroll = New-Object System.Windows.Controls.ScrollViewer
$scroll.HorizontalScrollBarVisibility = "Auto"
$scroll.VerticalScrollBarVisibility = "Auto"

$stack = New-Object System.Windows.Controls.StackPanel

for ($i=1; $i -le 50; $i++) {
    $txt = New-Object System.Windows.Controls.TextBlock
    $txt.Text = "Item $i"
    $stack.Children.Add($txt)
}

$scroll.Content = $stack
$window.Content = $scroll
```

- **Notes:** Essential when child content exceeds visible space.

---

# SECTION 5 — TABCONTROL

```pwsh
$tab = New-Object System.Windows.Controls.TabControl

$tab1 = New-Object System.Windows.Controls.TabItem
$tab1.Header = "Tab 1"
$tab1.Content = (New-Object System.Windows.Controls.TextBlock -Property @{Text="Content 1"})

$tab2 = New-Object System.Windows.Controls.TabItem
$tab2.Header = "Tab 2"
$tab2.Content = (New-Object System.Windows.Controls.TextBlock -Property @{Text="Content 2"})

$tab.Items.Add($tab1)
$tab.Items.Add($tab2)

$window.Content = $tab
```

- **Notes:** Each TabItem can hold any WPF content.

---

# SECTION 6 — TREEVIEW

```pwsh
$tree = New-Object System.Windows.Controls.TreeView

$root = New-Object System.Windows.Controls.TreeViewItem
$root.Header = "Root Node"

$child1 = New-Object System.Windows.Controls.TreeViewItem
$child1.Header = "Child 1"

$child2 = New-Object System.Windows.Controls.TreeViewItem
$child2.Header = "Child 2"

$root.Items.Add($child1)
$root.Items.Add($child2)

$tree.Items.Add($root)
$window.Content = $tree
```

- **Notes:** TreeView is ideal for hierarchical data; supports selection events.

---

# SECTION 7 — DATAGRID

```pwsh
$dataGrid = New-Object System.Windows.Controls.DataGrid
$dataGrid.AutoGenerateColumns = $true

# Sample data as PowerShell objects
$data = @(
    [PSCustomObject]@{ Name="Alice"; Age=25 },
    [PSCustomObject]@{ Name="Bob"; Age=30 },
    [PSCustomObject]@{ Name="Charlie"; Age=28 }
)

$dataGrid.ItemsSource = $data
$window.Content = $dataGrid
```

- **Notes:** DataGrid can sort, edit, and bind to collections.

---

# SECTION 8 — DYNAMIC LAYOUT

- **Change panel orientation / children dynamically**

```pwsh
$stack.Orientation = "Horizontal"
$btnNew = New-Object System.Windows.Controls.Button
$btnNew.Content = "Added Later"
$stack.Children.Add($btnNew)
```

- **Notes:** WPF + PowerShell allows full runtime manipulation; controls can be added, removed, or rearranged dynamically.

---

# SECTION 9 — SUMMARY

- Layout containers (StackPanel, DockPanel, WrapPanel, Grid) define arrangement.
- ScrollViewer handles overflow.
- TabControl supports multiple pages/tabs.
- TreeView for hierarchical data.
- DataGrid for tabular data.
- Controls can be dynamically created and added at runtime.
- Full flexibility for complex layouts.
