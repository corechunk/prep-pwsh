# 📂 File 15 — Advanced UI: Icons, Images, Sliding Panels, MenuBars in WPF + PowerShell

---

# THEORY

WPF allows deep customization of windows and controls:

1. **Window Icon** – set `.Icon` to a `.ico` or `BitmapFrame`.
2. **Window Title** – `.Title` property.
3. **Images** – `System.Windows.Controls.Image` can show PNG/JPG/etc.
4. **Buttons with Images** – `Button.Content` can be a StackPanel with Image + Text.
5. **Sliding Panels / Resizable Panels** – using `Grid` with `GridSplitter`.
6. **Custom MenuBars** – `Menu` control with `MenuItem`s.
7. **Backgrounds, Borders, Opacity** – set via `Background`, `BorderBrush`, `BorderThickness`, `Opacity`.
8. **Hover / Visual Feedback** – change background or effects on `MouseEnter`/`MouseLeave`.

# SECTION 1 — WINDOW ICON & TITLE

```pwsh
$window = New-Object System.Windows.Window
$window.Title = "My Custom App"

# Set icon (must be .ico)
$iconUri = New-Object System.Uri "C:\Path\To\icon.ico", [System.UriKind]::Absolute
$window.Icon = [System.Windows.Media.Imaging.BitmapFrame]::Create($iconUri)

$window.Width = 400
$window.Height = 300
$window.ShowDialog()
```

---

# SECTION 2 — IMAGE CONTROL

```pwsh
$img = New-Object System.Windows.Controls.Image
$uri = New-Object System.Uri "C:\Path\To\image.png", [System.UriKind]::Absolute
$bitmap = New-Object System.Windows.Media.Imaging.BitmapImage($uri)
$img.Source = $bitmap
$img.Width = 200
$img.Height = 200

$window.Content = $img
```

# SECTION 3 — BUTTON WITH IMAGE

```pwsh
$btn = New-Object System.Windows.Controls.Button
$btn.Width = 150
$btn.Height = 50

$stack = New-Object System.Windows.Controls.StackPanel
$stack.Orientation = "Horizontal"

$img = New-Object System.Windows.Controls.Image
$img.Source = $bitmap
$img.Width = 20
$img.Height = 20
$stack.Children.Add($img)

$txt = New-Object System.Windows.Controls.TextBlock
$txt.Text = "Click Me"
$txt.Margin = [System.Windows.Thickness]::new(5,0,0,0)
$stack.Children.Add($txt)

$btn.Content = $stack
$btn.Add_Click({ Write-Host "Button with image clicked" })

$window.Content = $btn
```

# SECTION 4 — GRID + SLIDING PANEL (GridSplitter)

```pwsh
$grid = New-Object System.Windows.Controls.Grid

# Columns
$col1 = New-Object System.Windows.Controls.ColumnDefinition
$col1.Width = [System.Windows.GridLength]::new(200, [System.Windows.GridUnitType]::Pixel)
$col2 = New-Object System.Windows.Controls.ColumnDefinition
$col2.Width = [System.Windows.GridLength]::new(5, [System.Windows.GridUnitType]::Pixel)
$col3 = New-Object System.Windows.Controls.ColumnDefinition
$col3.Width = [System.Windows.GridLength]::new(1, [System.Windows.GridUnitType]::Star)

$grid.ColumnDefinitions.Add($col1)
$grid.ColumnDefinitions.Add($col2)
$grid.ColumnDefinitions.Add($col3)

# Left panel
$leftPanel = New-Object System.Windows.Controls.StackPanel
$leftPanel.Background = [System.Windows.Media.Brushes]::LightBlue
[System.Windows.Controls.Grid]::SetColumn($leftPanel, 0)
$grid.Children.Add($leftPanel)

# GridSplitter
$splitter = New-Object System.Windows.Controls.GridSplitter
$splitter.Width = 5
$splitter.Background = [System.Windows.Media.Brushes]::Gray
$splitter.HorizontalAlignment = "Stretch"
$splitter.VerticalAlignment = "Stretch"
[System.Windows.Controls.Grid]::SetColumn($splitter, 1)
$grid.Children.Add($splitter)

# Right panel
$rightPanel = New-Object System.Windows.Controls.StackPanel
$rightPanel.Background = [System.Windows.Media.Brushes]::Beige
[System.Windows.Controls.Grid]::SetColumn($rightPanel, 2)
$grid.Children.Add($rightPanel)

$window.Content = $grid
```

# SECTION 5 — CUSTOM TOP MENU BAR

```pwsh
$menu = New-Object System.Windows.Controls.Menu

$menuFile = New-Object System.Windows.Controls.MenuItem
$menuFile.Header = "File"

$menuOpen = New-Object System.Windows.Controls.MenuItem
$menuOpen.Header = "Open"
$menuOpen.Add_Click({ Write-Host "Open clicked" })
$menuFile.Items.Add($menuOpen)

$menuExit = New-Object System.Windows.Controls.MenuItem
$menuExit.Header = "Exit"
$menuExit.Add_Click({ $window.Close() })
$menuFile.Items.Add($menuExit)

$menu.Items.Add($menuFile)

$stackMain = New-Object System.Windows.Controls.StackPanel
$stackMain.Children.Add($menu)

# Add main content below menu
$txt = New-Object System.Windows.Controls.TextBlock
$txt.Text = "Main Content"
$txt.Margin = [System.Windows.Thickness]::new(10)
$stackMain.Children.Add($txt)

$window.Content = $stackMain
```

# SECTION 6 — BACKGROUND & BORDERS

```pwsh
$border = New-Object System.Windows.Controls.Border
$border.Width = 300
$border.Height = 200
$border.Background = [System.Windows.Media.Brushes]::LightYellow
$border.BorderBrush = [System.Windows.Media.Brushes]::DarkOrange
$border.BorderThickness = [System.Windows.Thickness]::new(5)
$border.CornerRadius = [System.Windows.CornerRadius]::new(10)

$txt = New-Object System.Windows.Controls.TextBlock
$txt.Text = "Bordered Content"
$txt.HorizontalAlignment = "Center"
$txt.VerticalAlignment = "Center"
$border.Child = $txt

$window.Content = $border
```
