# 📂 File 01 — Window (Root Container)

## THEORY

The Window is the top-level container in WPF.  
Everything in a WPF application must live inside a Window.

### Core Capabilities

- Title
- Icon
- Resize behavior
- Startup position
- Custom title bar (remove default chrome)
- Transparency
- Modal dialog behavior
- Window ownership
- Events lifecycle

### Important Properties

- `Title`
- `Width`
- `Height`
- `ResizeMode`
- `WindowStartupLocation`
- `WindowStyle`
- `AllowsTransparency`
- `Background`
- `Icon`

### Important Events

- `Loaded`
- `Closing`
- `Closed`
- `SizeChanged`
- `Activated`
- `Deactivated`
- `LocationChanged`

## FULL WORKING EXAMPLE (PS 5.1 + PS 7.1 Compatible)

```pwsh
# Load required WPF assemblies
Add-Type -AssemblyName PresentationFramework
Add-Type -AssemblyName PresentationCore
Add-Type -AssemblyName WindowsBase

# Define XAML
[xml]$xaml = @"
<Window
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="Main Window"
    Width="600"
    Height="400"
    WindowStartupLocation="CenterScreen"
    ResizeMode="CanResize"
    Background="#1E1E1E">

    <Grid>
        <TextBlock
            Text="Hello from WPF + PowerShell"
            Foreground="White"
            FontSize="20"
            HorizontalAlignment="Center"
            VerticalAlignment="Center"/>
    </Grid>

</Window>
"@

# Load XAML
$reader = New-Object System.Xml.XmlNodeReader $xaml
$window = [Windows.Markup.XamlReader]::Load($reader)

# Attach events
$window.Add_Loaded({
    Write-Host "Window Loaded"
})

$window.Add_Closing({
    Write-Host "Window Closing"
})

# Show window
$window.ShowDialog() | Out-Null
```

## ADVANCED WINDOW CONFIGURATIONS

### Remove Default Title Bar (Custom Chrome)

```xml
<Window
    WindowStyle="None"
    AllowsTransparency="True"
    Background="Transparent">
```

To allow dragging:

```pwsh
$window.Add_MouseLeftButtonDown({
    $window.DragMove()
})
```

---

### Set Window Icon

```pwsh
$window.Icon = "app.ico"
```

(.ico format required)

---

### Disable Resize

```pwsh
ResizeMode="NoResize"
```

---

### Transparent Window

```pwsh
AllowsTransparency="True"
Background="Transparent"
```

Note: Transparency requires `WindowStyle="None"`.

---

## KEY CONCEPTS

- A Window is both a visual container and a lifecycle controller.
- Only one window is typically the main application window.
- `Show()` is modeless.
- `ShowDialog()` is modal (blocks execution).
- Custom chrome allows full UI redesign capability.
