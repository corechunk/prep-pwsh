# 📂 File 04 — Menu, ContextMenu & ToolBar System

## THEORY

Menus in WPF provide structured command navigation.

There are three primary menu-related components:

- `Menu` → Top application menu bar
- `ContextMenu` → Right-click menu
- `ToolBar` → Icon/button strip for quick actions

Menus in WPF support:

- Nested submenus
- Icons inside menu items
- Separators
- Keyboard shortcuts (InputGestureText)
- Routed events
- Command binding
- Dynamic runtime modification

Menus use `MenuItem` as the core unit.

---

# SECTION 1 — TOP MENU BAR (Menu)

## FULL WORKING EXAMPLE

```pwsh
Add-Type -AssemblyName PresentationFramework
Add-Type -AssemblyName PresentationCore
Add-Type -AssemblyName WindowsBase

[xml]$xaml = @"
<Window
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    Title="Menu Example"
    Width="600"
    Height="400"
    WindowStartupLocation="CenterScreen">

    <DockPanel>

        <!-- Top Menu -->
        <Menu DockPanel.Dock="Top">
            <MenuItem Header="_File" Name="menuFile">
                <MenuItem Header="_Open" Name="menuOpen" InputGestureText="Ctrl+O"/>
                <Separator/>
                <MenuItem Header="_Exit" Name="menuExit"/>
            </MenuItem>

            <MenuItem Header="_Edit">
                <MenuItem Header="_Copy"/>
                <MenuItem Header="_Paste"/>
            </MenuItem>

            <MenuItem Header="_Help">
                <MenuItem Header="_About"/>
            </MenuItem>
        </Menu>

        <!-- Main Content -->
        <Grid Background="#2C3E50">
            <TextBlock Text="Main Content Area"
                       Foreground="White"
                       FontSize="18"
                       HorizontalAlignment="Center"
                       VerticalAlignment="Center"/>
        </Grid>

    </DockPanel>

</Window>
"@

$reader = New-Object System.Xml.XmlNodeReader $xaml
$window = [Windows.Markup.XamlReader]::Load($reader)

$menuOpen = $window.FindName("menuOpen")
$menuExit = $window.FindName("menuExit")

$menuOpen.Add_Click({
    [System.Windows.MessageBox]::Show("Open clicked")
})

$menuExit.Add_Click({
    $window.Close()
})

$window.ShowDialog() | Out-Null
```

# SECTION 2 — MENU STRUCTURE DETAILS

## Header Underscore (_)

Underscore defines keyboard access key:

```xml
<MenuItem Header="_File"/>
```

Alt + F activates it.

---

## Separators

```xml
<Separator/>
```

Visually divides groups.

---

# SECTION 3 — MENU ITEM WITH ICON

MenuItem is also a ContentControl.

```xml
<MenuItem Header="Open">
    <MenuItem.Icon>
        <Image Source="icon.png" Width="16" Height="16"/>
    </MenuItem.Icon>
</MenuItem>
```

Icons align automatically left.

---

# SECTION 4 — CONTEXT MENU (Right Click Menu)

## THEORY

ContextMenu attaches to any control.

Appears on right-click.

---

## Example

```xml
<Button Content="Right Click Me" Width="150" Height="40">
    <Button.ContextMenu>
        <ContextMenu>
            <MenuItem Header="Option 1" Name="ctxOpt1"/>
            <MenuItem Header="Option 2" Name="ctxOpt2"/>
        </ContextMenu>
    </Button.ContextMenu>
</Button>
```

To attach event:

```pwsh
$ctxOpt1 = $window.FindName("ctxOpt1")
$ctxOpt1.Add_Click({
    Write-Host "Context Option 1"
})
```

---

# SECTION 5 — TOOLBAR

## THEORY

ToolBar is used for icon-based quick access commands.

Usually placed at top under menu.

---

## Example

```xml
<DockPanel>

    <ToolBarTray DockPanel.Dock="Top">
        <ToolBar>
            <Button Name="tbNew" Content="New"/>
            <Button Name="tbSave" Content="Save"/>
        </ToolBar>
    </ToolBarTray>

    <Grid Background="LightGray"/>

</DockPanel>
```

Attach events:

```pwsh
$tbNew = $window.FindName("tbNew")
$tbNew.Add_Click({ Write-Host "New clicked" })
```

# SECTION 6 — SHORTCUT KEYS (Keyboard Bindings)

`InputGestureText` only shows text.
It does NOT create the shortcut.

To implement actual shortcut:

```pwsh
$window.Add_KeyDown({
    if ($_.KeyboardDevice.Modifiers -eq "Control" -and $_.Key -eq "O") {
        Write-Host "Ctrl+O pressed"
    }
})
```

Advanced approach uses `InputBindings`.

---

# SECTION 7 — CHECKABLE MENU ITEMS

MenuItem can act like checkbox.

```xml
<MenuItem Header="Enable Feature"
          IsCheckable="True"
          Name="menuToggle"/>
```

Handle toggle:

```pwsh
$menuToggle = $window.FindName("menuToggle")
$menuToggle.Add_Click({
    Write-Host "Checked state: $($menuToggle.IsChecked)"
})
```

---

# SECTION 8 — RADIO STYLE MENU ITEMS

GroupName property:

```xml
<MenuItem Header="Theme Light" IsCheckable="True" GroupName="ThemeGroup"/>
<MenuItem Header="Theme Dark" IsCheckable="True" GroupName="ThemeGroup"/>
```

Only one selected at a time.

---

# SECTION 9 — DYNAMICALLY ADD MENU ITEMS

You can modify menu at runtime.

```pwsh
$newItem = New-Object System.Windows.Controls.MenuItem
$newItem.Header = "Dynamic Option"
$newItem.Add_Click({ Write-Host "Dynamic Clicked" })

$menuFile.Items.Add($newItem)
```

---

# SECTION 10 — DISABLING MENU ITEMS

```pwsh
$menuOpen.IsEnabled = $false
```

---

# SECTION 11 — CUSTOM STYLING

MenuItem supports styling like Button.

Example:

```xml
<MenuItem>
    <MenuItem.Style>
        <Style TargetType="MenuItem">
            <Setter Property="Background" Value="DarkSlateBlue"/>
            <Setter Property="Foreground" Value="White"/>
        </Style>
    </MenuItem.Style>
</MenuItem>
```
