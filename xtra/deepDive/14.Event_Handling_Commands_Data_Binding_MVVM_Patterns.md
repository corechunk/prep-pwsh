# 📂 File 14 — Event Handling, Commands & Data Binding in WPF + PowerShell

---

# THEORY

WPF events are very rich. Beyond `Add_Click`, almost every control has multiple events for interaction and appearance changes. You can attach handlers to handle mouse, keyboard, focus, drag, hover, selection, and more.

**Key event categories:**

1. **Mouse Events** – `MouseEnter`, `MouseLeave`, `MouseMove`, `MouseDown`, `MouseUp`, `MouseWheel`.
2. **Keyboard Events** – `KeyDown`, `KeyUp`, `PreviewKeyDown`, `PreviewKeyUp`.
3. **Focus Events** – `GotFocus`, `LostFocus`.
4. **Control-specific events** – e.g., `TextChanged` (TextBox), `SelectionChanged` (ComboBox/ListBox), `Checked`/`Unchecked` (CheckBox/RadioButton).
5. **Window Events** – `Loaded`, `Closing`, `Closed`, `SizeChanged`, `Activated`, `Deactivated`.
6. **Custom Routed Events** – `Button.Click`, `CommandExecuted`, etc.

# SECTION 1 — BUTTON EVENTS

```pwsh
$btn = New-Object System.Windows.Controls.Button
$btn.Content = "Hover & Click Me"
$btn.Width = 150
$btn.Height = 50

# Click
$btn.Add_Click({
    Write-Host "Button Clicked!"
})

# Mouse Enter / Leave
$btn.Add_MouseEnter({
    $btn.Background = [System.Windows.Media.Brushes]::LightGreen
})
$btn.Add_MouseLeave({
    $btn.Background = [System.Windows.Media.Brushes]::LightGray
})

# Right-Click
$btn.Add_MouseRightButtonUp({
    Write-Host "Right button released"
})

$window.Content = $btn
```

# SECTION 2 — TEXTBOX EVENTS

```pwsh
$txt = New-Object System.Windows.Controls.TextBox
$txt.Width = 200
$txt.Margin = [System.Windows.Thickness]::new(10)

# Text changed
$txt.Add_TextChanged({
    Write-Host "Text is now: $($txt.Text)"
})

# Focus
$txt.Add_GotFocus({
    Write-Host "TextBox got focus"
})
$txt.Add_LostFocus({
    Write-Host "TextBox lost focus"
})

$window.Content = $txt
```

# SECTION 3 — WINDOW EVENTS

```pwsh
# Loaded
$window.Add_Loaded({
    Write-Host "Window fully loaded"
})

# Closing
$window.Add_Closing({
    param($sender,$args)
    Write-Host "Window closing"
    # $args.Cancel = $true  # cancel closing if needed
})

# Size Changed
$window.Add_SizeChanged({
    Write-Host "Window size changed: $($window.Width)x$($window.Height)"
})
```

# SECTION 4 — COMMANDS (RoutedCommands)

```pwsh
$btn = New-Object System.Windows.Controls.Button
$btn.Content = "Save"

$saveCommand = [System.Windows.Input.RoutedCommand]::new("SaveCommand",$null)

$btn.Command = $saveCommand

$cmdBinding = New-Object System.Windows.Input.CommandBinding($saveCommand)
$cmdBinding.Executed += {
    Write-Host "Save command executed!"
}
$window.CommandBindings.Add($cmdBinding)

$window.Content = $btn
```

# SECTION 5 — DATA BINDING BASICS

```pwsh
$txtBox = New-Object System.Windows.Controls.TextBox
$txtBox.Width = 200

# Create a simple observable property
$global:NameProperty = "John"

# Bind TextBox.Text to $global:NameProperty
$binding = New-Object System.Windows.Data.Binding "NameProperty"
$binding.Source = $global
$binding.Mode = [System.Windows.Data.BindingMode]::TwoWay
$txtBox.SetBinding([System.Windows.Controls.TextBox]::TextProperty,$binding)

$window.Content = $txtBox
```

# SECTION 6 — CHECKBOX / SELECTION EVENTS

```pwsh
$chk = New-Object System.Windows.Controls.CheckBox
$chk.Content = "Enable Feature"

$chk.Add_Checked({ Write-Host "Checked" })
$chk.Add_Unchecked({ Write-Host "Unchecked" })

$lst = New-Object System.Windows.Controls.ListBox
$lst.Items.Add("Item 1")
$lst.Items.Add("Item 2")
$lst.Items.Add("Item 3")
$lst.Add_SelectionChanged({ Write-Host "Selected: $($lst.SelectedItem)" })

$stack = New-Object System.Windows.Controls.StackPanel
$stack.Children.Add($chk)
$stack.Children.Add($lst)
$window.Content = $stack
```

# SECTION 7 — MOUSE / DRAG EVENTS

```pwsh
$rect = New-Object System.Windows.Shapes.Rectangle
$rect.Width = 100
$rect.Height = 50
$rect.Fill = [System.Windows.Media.Brushes]::Blue

# Drag detection
$rect.Add_MouseDown({
    Write-Host "Drag started"
})
$rect.Add_MouseMove({
    if ($_.LeftButton -eq "Pressed") {
        Write-Host "Dragging at $($_.GetPosition($window))"
    }
})
$rect.Add_MouseUp({
    Write-Host "Drag ended"
})

$window.Content = $rect
```

# SECTION 8 — HOVER / TOOLTIP

```pwsh
$btn = New-Object System.Windows.Controls.Button
$btn.Content = "Hover me"
$btn.ToolTip = "I am a tooltip"

$btn.Add_MouseEnter({
    Write-Host "Hovering button"
})
$btn.Add_MouseLeave({
    Write-Host "Left hover"
})

$window.Content = $btn
```

# SECTION 9 — SUMMARY

- WPF + PowerShell allows **rich event handling**.
- Use `.Add_<EventName>` syntax for events.
- Commands and RoutedCommands separate UI action from logic.
- Data binding enables MVVM-like behavior, including TwoWay bindings.
- Any interactive element can have mouse, keyboard, focus, selection, and drag events.
- ToolTips, hover effects, and other visual feedback are supported.
