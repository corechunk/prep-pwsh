# 📂 File 12 — Styling, Templates & Themes in WPF + PowerShell

---

# THEORY

WPF supports a rich styling and templating system. Styles, Templates, and Themes allow separation of logic and appearance.

Key concepts:

1. **Brushes** — Define the fill or stroke of a control.
   - `SolidColorBrush`, `LinearGradientBrush`, `RadialGradientBrush`, `ImageBrush`
2. **Fonts** — `FontFamily`, `FontSize`, `FontWeight`, `FontStyle`, `Foreground`
3. **Borders & Padding** — Control the space inside/outside a control.
4. **Control Templates** — Replace the visual structure of a control.
5. **Data Templates** — Define the layout for data-bound items.
6. **Dynamic Resources & Themes** — Define reusable styles and switch them dynamically.

---

# SECTION 1 — BASIC STYLING

```pwsh
$btn = New-Object System.Windows.Controls.Button
$btn.Content = "Styled Button"
$btn.Width = 150
$btn.Height = 50

# Background and Foreground
$btn.Background = [System.Windows.Media.Brushes]::LightCoral
$btn.Foreground = [System.Windows.Media.Brushes]::White

# Font styling
$btn.FontSize = 16
$btn.FontWeight = "Bold"
$btn.FontFamily = "Arial"

$window.Content = $btn
```

# SECTION 2 — BORDERS & PADDING

```pwsh
$border = New-Object System.Windows.Controls.Border
$border.Width = 200
$border.Height = 100
$border.BorderBrush = [System.Windows.Media.Brushes]::DarkBlue
$border.BorderThickness = 3
$border.Padding = 10
$border.CornerRadius = [System.Windows.CornerRadius]::new(10)

$text = New-Object System.Windows.Controls.TextBlock
$text.Text = "Hello WPF"
$text.HorizontalAlignment = "Center"
$text.VerticalAlignment = "Center"

$border.Child = $text
$window.Content = $border
```

# SECTION 3 — GRADIENT BRUSHES

```pwsh
$rect = New-Object System.Windows.Shapes.Rectangle
$rect.Width = 200
$rect.Height = 100

$grad = New-Object System.Windows.Media.LinearGradientBrush
$grad.StartPoint = [System.Windows.Point]::new(0,0)
$grad.EndPoint = [System.Windows.Point]::new(1,1)

$grad.GradientStops.Add((New-Object System.Windows.Media.GradientStop([System.Windows.Media.Colors]::Red, 0)))
$grad.GradientStops.Add((New-Object System.Windows.Media.GradientStop([System.Windows.Media.Colors]::Yellow, 0.5)))
$grad.GradientStops.Add((New-Object System.Windows.Media.GradientStop([System.Windows.Media.Colors]::Green, 1)))

$rect.Fill = $grad
$window.Content = $rect
```

# SECTION 4 — CONTROL TEMPLATES

```pwsh
# Re-template a Button
$btn = New-Object System.Windows.Controls.Button
$btn.Content = "Custom Template"

$templateXaml = @"
<ControlTemplate xmlns='http://schemas.microsoft.com/winfx/2006/xaml/presentation' TargetType='Button'>
    <Border Background='Orange' BorderBrush='Black' BorderThickness='2' CornerRadius='8'>
        <ContentPresenter HorizontalAlignment='Center' VerticalAlignment='Center'/>
    </Border>
</ControlTemplate>
"@

$reader = (New-Object System.Xml.XmlNodeReader ([xml]$templateXaml))
$template = [Windows.Markup.XamlReader]::Load($reader)
$btn.Template = $template

$window.Content = $btn
```

# SECTION 5 — DATA TEMPLATES

```pwsh
$list = New-Object System.Windows.Controls.ListBox
$list.Width = 200
$list.Height = 150

$dataTemplateXaml = @"
<DataTemplate xmlns='http://schemas.microsoft.com/winfx/2006/xaml/presentation'>
    <StackPanel Orientation='Horizontal'>
        <Ellipse Width='20' Height='20' Fill='Blue' Margin='5'/>
        <TextBlock Text='{Binding Name}' VerticalAlignment='Center'/>
    </StackPanel>
</DataTemplate>
"@

$reader = (New-Object System.Xml.XmlNodeReader ([xml]$dataTemplateXaml))
$dataTemplate = [Windows.Markup.XamlReader]::Load($reader)

$list.ItemTemplate = $dataTemplate
$list.ItemsSource = @(@{Name="Alice"}, @{Name="Bob"}, @{Name="Charlie"})

$window.Content = $list
```

# SECTION 6 — DYNAMIC RESOURCES & THEMES

```pwsh
# Define a resource dictionary dynamically
$window.Resources["MainBrush"] = [System.Windows.Media.Brushes]::LightBlue

$btn = New-Object System.Windows.Controls.Button
$btn.Content = "Dynamic Theme"
$btn.Background = $window.Resources["MainBrush"]

# Change resource at runtime
Start-Sleep -Seconds 2
$window.Resources["MainBrush"] = [System.Windows.Media.Brushes]::LightGreen

$window.Content = $btn
```

# SECTION 7 — IMAGES & ICONS

```pwsh

$iconUri = [Uri]::new("C:\Path\To\icon.ico")
```

# SECTION 8 — SLIDING PANEL WITH MOUSE

```pwsh
$grid = New-Object System.Windows.Controls.Grid
$col1 = New-Object System.Windows.Controls.ColumnDefinition
$col1.Width = [System.Windows.GridLength]::new(200)
$col2 = New-Object System.Windows.Controls.ColumnDefinition
$col2.Width = [System.Windows.GridLength]::new(1,*)
$grid.ColumnDefinitions.Add($col1)
$grid.ColumnDefinitions.Add($col2)

$panel = New-Object System.Windows.Controls.StackPanel
$panel.Background = [System.Windows.Media.Brushes]::Gray
[System.Windows.Controls.Grid]::SetColumn($panel,0)

# Mouse drag to resize width
$panel.Add_MouseMove({
    param($s,$e)
    if ($e.LeftButton -eq "Pressed") {
        $col1.Width = [System.Windows.GridLength]::new($e.GetPosition($window).X)
    }
})

$grid.Children.Add($panel)
$window.Content = $grid
```
