# 📂 File 06 — Custom Title Bar, Window Chrome & Advanced Window Control

## THEORY

WPF windows are highly customizable.

By default, Windows provides:

- Title bar
- Minimize / Maximize / Close buttons
- Resize border
- System icon
- Drag behavior
- System menu (Alt+Space)

But WPF allows:

- Removing default chrome
- Creating fully custom title bars
- Custom window buttons
- Borderless windows
- Transparent windows
- Manual resize handling
- DragMove implementation
- Custom window shadows
- Topmost windows
- Modal vs modeless windows
- Window ownership
- Custom system menu behavior

All examples below work in:

- PowerShell 5.1 (Windows PowerShell)
- PowerShell 7.1 (Windows on .NET Core)

---

# SECTION 1 — REMOVING DEFAULT TITLE BAR

To create a borderless window:

```xml
<Window
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    Title="Custom Chrome"
    Width="600"
    Height="400"
    WindowStyle="None"
    ResizeMode="CanResize"
    Background="White">
```

Important properties:

- WindowStyle="None" → removes title bar
- ResizeMode controls resizing
- AllowsTransparency can enable transparent window

# SECTION 2 — BASIC CUSTOM TITLE BAR

## FULL WORKING EXAMPLE

```pwsh
Add-Type -AssemblyName PresentationFramework
Add-Type -AssemblyName PresentationCore
Add-Type -AssemblyName WindowsBase

[xml]$xaml = @"
<Window
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    Title="Custom Window"
    Width="600"
    Height="400"
    WindowStyle="None"
    ResizeMode="CanResize"
    Background="White"
    WindowStartupLocation="CenterScreen">

    <Border BorderBrush="#444" BorderThickness="1">

        <Grid>

            <Grid.RowDefinitions>
                <RowDefinition Height="35"/>
                <RowDefinition Height="*"/>
            </Grid.RowDefinitions>

            <!-- Custom Title Bar -->
            <Grid Name="TitleBar"
                  Background="#222"
                  Grid.Row="0">

                <Grid.ColumnDefinitions>
                    <ColumnDefinition Width="*"/>
                    <ColumnDefinition Width="40"/>
                    <ColumnDefinition Width="40"/>
                    <ColumnDefinition Width="40"/>
                </Grid.ColumnDefinitions>

                <TextBlock Text="My Custom Window"
                           Foreground="White"
                           VerticalAlignment="Center"
                           Margin="10,0"/>

                <Button Name="btnMin"
                        Content="_"
                        Grid.Column="1"/>

                <Button Name="btnMax"
                        Content="□"
                        Grid.Column="2"/>

                <Button Name="btnClose"
                        Content="X"
                        Grid.Column="3"
                        Background="#AA2222"
                        Foreground="White"/>
            </Grid>

            <!-- Main Content -->
            <Grid Grid.Row="1">
                <TextBlock Text="Main Content Area"
                           HorizontalAlignment="Center"
                           VerticalAlignment="Center"
                           FontSize="18"/>
            </Grid>

        </Grid>

    </Border>
</Window>
"@

$reader = New-Object System.Xml.XmlNodeReader $xaml
$window = [Windows.Markup.XamlReader]::Load($reader)

$btnClose = $window.FindName("btnClose")
$btnMin   = $window.FindName("btnMin")
$btnMax   = $window.FindName("btnMax")
$titleBar = $window.FindName("TitleBar")

$btnClose.Add_Click({ $window.Close() })

$btnMin.Add_Click({
    $window.WindowState = "Minimized"
})

$btnMax.Add_Click({
    if ($window.WindowState -eq "Maximized") {
        $window.WindowState = "Normal"
    } else {
        $window.WindowState = "Maximized"
    }
})

# DragMove support
$titleBar.Add_MouseLeftButtonDown({
    $window.DragMove()
})

$window.ShowDialog() | Out-Null
```

# SECTION 3 — ENABLE RESIZING ON BORDERLESS WINDOW

When WindowStyle=None, resizing may not behave perfectly.

Ensure:

```xml
ResizeMode="CanResize"
```

You can also manually implement resize grips if needed.

---

# SECTION 4 — TRANSPARENT WINDOW

To create glass-style window:

```xml
<Window
    WindowStyle="None"
    AllowsTransparency="True"
    Background="Transparent">
```

Then use Border with rounded corners:

```xml
<Border Background="White"
        CornerRadius="15">
```

NOTE:

AllowsTransparency=True disables hardware acceleration in older systems.

---

# SECTION 5 — ALWAYS ON TOP

```pwsh
$window.Topmost = $true
```

Equivalent XAML:

```xml
Topmost="True"
```

---

# SECTION 6 — MODAL VS MODELESS

Modal:

```pwsh
$window.ShowDialog()
```

Modeless:

```pwsh
$window.Show()
```

Modal blocks calling script until closed.

---

# SECTION 7 — WINDOW OWNERSHIP

Set owner window:

```pwsh
$child.Owner = $parent
$child.ShowDialog()
```

This ensures:

- Child stays on top of parent
- Minimizing parent minimizes child

---

# SECTION 11 — CUSTOM SHADOW EFFECT

WPF does not auto-add shadow for borderless windows.

You can simulate:

```xml
<Border>
    <Border.Effect>
        <DropShadowEffect BlurRadius="20"
                          ShadowDepth="0"
                          Opacity="0.4"/>
    </Border.Effect>
</Border>
```

---

# SECTION 12 — SYSTEM MENU ACCESS

Show system menu:

```pwsh
$window.Add_KeyDown({
    if ($_.SystemKey -eq "Space") {
        Write-Host "System menu triggered"
    }
})
```

Advanced control requires Win32 interop (optional).

---

# SECTION 13 — DISABLE CLOSE BUTTON (DEFAULT WINDOW)

If keeping default chrome:

```pwsh
$window.Add_Closing({
    param($sender,$e)
    $e.Cancel = $true
})
```

---

# SECTION 14 — FULLSCREEN WINDOW

```pwsh
$window.WindowStyle = "None"
$window.WindowState = "Maximized"
```
