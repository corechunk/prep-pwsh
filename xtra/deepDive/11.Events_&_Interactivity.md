# 📂 File 11 — Events & Interactivity in WPF + PowerShell

---

# THEORY

WPF supports a vast range of events and interactivity options. PowerShell can attach event handlers dynamically to any WPF element.

Key concepts:

1. **Routed Events** — Events that can bubble up or tunnel down the visual tree.
   - Bubble: event moves up from child to parent.
   - Tunnel: event moves down from parent to child.
2. **Standard CLR Events** — Basic .NET events (e.g., `Add_Click` for Button).
3. **Keyboard Events** — `KeyDown`, `KeyUp`, `PreviewKeyDown`.
4. **Mouse Events** — `MouseEnter`, `MouseLeave`, `MouseMove`, `MouseDown`, `MouseUp`, `MouseWheel`.
5. **Focus Events** — `GotFocus`, `LostFocus`.
6. **Drag & Drop** — `DragEnter`, `DragLeave`, `Drop`, `DragOver`.
7. **Timers / Animations** — `DispatcherTimer` for repeated tasks; `Storyboard` for animations.
8. **Commands** — `ICommand` interface and `Button.Command` binding.

# SECTION 1 — BUTTON EVENTS
```pwsh
$btn = New-Object System.Windows.Controls.Button
$btn.Content = "Click Me"

# Click event
$btn.Add_Click({
    Write-Host "Button clicked!"
})

# Mouse Enter / Leave
$btn.Add_MouseEnter({
    $btn.Background = [System.Windows.Media.Brushes]::LightBlue
})
$btn.Add_MouseLeave({
    $btn.Background = [System.Windows.Media.Brushes]::White
})

# Right click example
$btn.Add_MouseRightButtonDown({
    Write-Host "Right clicked!"
})

$window.Content = $btn
```

# SECTION 2 — KEYBOARD EVENTS

```pwsh
$txtBox = New-Object System.Windows.Controls.TextBox
$txtBox.Width = 200

$txtBox.Add_KeyDown({
    param($sender,$e)
    if ($e.Key -eq "Enter") {
        Write-Host "Enter pressed: $($sender.Text)"
    }
})

$window.Content = $txtBox
```

---

# SECTION 3 — FOCUS EVENTS

```pwsh
$txt1 = New-Object System.Windows.Controls.TextBox
$txt2 = New-Object System.Windows.Controls.TextBox

$txt1.Add_GotFocus({
    $txt1.Background = [System.Windows.Media.Brushes]::LightYellow
})
$txt1.Add_LostFocus({
    $txt1.Background = [System.Windows.Media.Brushes]::White
})

$stack = New-Object System.Windows.Controls.StackPanel
$stack.Children.Add($txt1)
$stack.Children.Add($txt2)
$window.Content = $stack
```

# SECTION 4 — DRAG & DROP

```pwsh
$rect = New-Object System.Windows.Shapes.Rectangle
$rect.Width = 100
$rect.Height = 100
$rect.Fill = [System.Windows.Media.Brushes]::Red
$rect.AllowDrop = $true

$rect.Add_Drop({
    param($sender,$e)
    Write-Host "Dropped something!"
})

$rect.Add_DragEnter({
    $rect.Fill = [System.Windows.Media.Brushes]::Green
})
$rect.Add_DragLeave({
    $rect.Fill = [System.Windows.Media.Brushes]::Red
})

$window.Content = $rect
```

# SECTION 5 — TIMERS

```pwsh
$timer = New-Object System.Windows.Threading.DispatcherTimer
$timer.Interval = [TimeSpan]::FromSeconds(1)
$timer.Add_Tick({
    Write-Host "Tick: $(Get-Date)"
})
$timer.Start()
```

---

# SECTION 6 — ANIMATIONS

```pwsh
# Example: Animate button width
$btn = New-Object System.Windows.Controls.Button
$btn.Content = "Animate Me"

$anim = New-Object System.Windows.Media.Animation.DoubleAnimation
$anim.From = 100
$anim.To = 300
$anim.Duration = [System.Windows.Duration]::new([TimeSpan]::FromSeconds(2))

$btn.BeginAnimation([System.Windows.Controls.Button]::WidthProperty, $anim)

$window.Content = $btn
```

- **Notes:** WPF animations can target almost any dependency property.

---

# SECTION 7 — COMMANDS

```pwsh
$btn = New-Object System.Windows.Controls.Button
$btn.Content = "Save"

$saveCmd = New-Object System.Windows.Input.RoutedCommand
$btn.Command = $saveCmd

$window.Add_CommandBindings(
    New-Object System.Windows.Input.CommandBinding $saveCmd, {
        Write-Host "Save command executed!"
    }
)
$window.Content = $btn
```

---

# SECTION 8 — DYNAMIC EVENT ATTACHMENT

```pwsh
$btns = @()
for ($i=1; $i -le 5; $i++) {
    $b = New-Object System.Windows.Controls.Button
    $b.Content = "Btn $i"
    $b.Add_Click({ Write-Host "Clicked $i" })
    $btns += $b
}

$stack = New-Object System.Windows.Controls.StackPanel
$btns | ForEach-Object { $stack.Children.Add($_) }
$window.Content = $stack
```

- **Notes:** Events can be attached dynamically even in compiled script; use closures to capture variables.

# SECTION 9 — SUMMARY

- PowerShell + WPF supports a wide variety of events.
- Buttons, TextBoxes, and other controls expose multiple mouse, keyboard, and focus events.
- Timers and animations allow dynamic behavior.
- Commands and RoutedEvents provide structured interaction.
- Drag & Drop allows advanced interactivity.
