# 📂 File 03 — Panels & Layout System (Grid, StackPanel, DockPanel, WrapPanel, Canvas, UniformGrid, GridSplitter)

## THEORY

In WPF, **layout is everything**.

Controls do not position themselves.
Panels control layout behavior.

Every layout container inherits from `Panel`, but each one follows different layout logic.

Understanding panels is critical for:

- Responsive UI
- Sliding panels
- Sidebars
- Resizable layouts
- Dashboard-style apps
- Complex nested UI

---

# PANEL OVERVIEW

| Panel Type     | Behavior Model |
|---------------|----------------|
| Grid          | Row/Column structured layout |
| StackPanel    | Linear vertical/horizontal stacking |
| DockPanel     | Dock elements to edges |
| WrapPanel     | Wrap items when space runs out |
| UniformGrid   | Equal-sized grid cells |
| Canvas        | Absolute positioning |
| GridSplitter  | Resizable grid sections |

---

# SECTION 1 — GRID (Most Powerful Layout Panel)

## THEORY

Grid divides space into rows and columns.
It is the most flexible and most commonly used layout container.

You define:
- RowDefinitions
- ColumnDefinitions

You place elements using:
- Grid.Row
- Grid.Column

---

## FULL WORKING GRID EXAMPLE

```pwsh
Add-Type -AssemblyName PresentationFramework
Add-Type -AssemblyName PresentationCore
Add-Type -AssemblyName WindowsBase

[xml]$xaml = @"
<Window
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    Title="Grid Example"
    Width="500"
    Height="300"
    WindowStartupLocation="CenterScreen">

    <Grid>
        <Grid.RowDefinitions>
            <RowDefinition Height="Auto"/>
            <RowDefinition Height="*"/>
        </Grid.RowDefinitions>

        <Grid.ColumnDefinitions>
            <ColumnDefinition Width="200"/>
            <ColumnDefinition Width="*"/>
        </Grid.ColumnDefinitions>

        <Border Grid.Row="0" Grid.ColumnSpan="2" Background="DarkSlateBlue">
            <TextBlock Text="Header"
                       Foreground="White"
                       Margin="10"/>
        </Border>

        <Border Grid.Row="1" Grid.Column="0" Background="#2C3E50">
            <TextBlock Text="Sidebar"
                       Foreground="White"
                       Margin="10"/>
        </Border>

        <Border Grid.Row="1" Grid.Column="1" Background="#34495E">
            <TextBlock Text="Main Content"
                       Foreground="White"
                       Margin="10"/>
        </Border>

    </Grid>
</Window>
"@

$reader = New-Object System.Xml.XmlNodeReader $xaml
$window = [Windows.Markup.XamlReader]::Load($reader)
$window.ShowDialog() | Out-Null
```

---

## Grid Sizing Modes

- `Auto` → size to content
- `*` → proportional sizing
- Fixed pixel → `Width="200"`

Example:

```xml
<RowDefinition Height="2*"/>
<RowDefinition Height="3*"/>
```

Row 2 is 1.5x larger than row 1.

# SECTION 2 — STACKPANEL

## THEORY

StackPanel stacks elements:

- Vertical (default)
- Horizontal

It does NOT resize proportionally like Grid.
It grows based on content.

---

## Example

```xml
<StackPanel Orientation="Vertical">
    <Button Content="One"/>
    <Button Content="Two"/>
    <Button Content="Three"/>
</StackPanel>
```

Horizontal:

```xml
<StackPanel Orientation="Horizontal">
    <Button Content="Left"/>
    <Button Content="Right"/>
</StackPanel>
```

---

# SECTION 3 — DOCKPANEL

## THEORY

DockPanel docks children to edges:

- Top
- Bottom
- Left
- Right

The last element fills remaining space.

---

## Example

```xml
<DockPanel>
    <Border DockPanel.Dock="Top" Height="40" Background="DarkBlue"/>
    <Border DockPanel.Dock="Left" Width="150" Background="Gray"/>
    <Border Background="LightGray"/>
</DockPanel>
```

The final Border fills remaining area.

---

# SECTION 4 — WRAPPANEL

## THEORY

WrapPanel places items in a row until space runs out, then wraps.

Perfect for:
- Thumbnail galleries
- Tag lists
- Dynamic button sets

---

## Example

```xml
<WrapPanel>
    <Button Content="Item 1"/>
    <Button Content="Item 2"/>
    <Button Content="Item 3"/>
    <Button Content="Item 4"/>
</WrapPanel>
```

---

# SECTION 5 — UNIFORMGRID

## THEORY

UniformGrid creates equal-sized cells.

You define rows and columns.
All cells are equal size.

---

## Example

```xml
<UniformGrid Rows="2" Columns="2">
    <Button Content="A"/>
    <Button Content="B"/>
    <Button Content="C"/>
    <Button Content="D"/>
</UniformGrid>
```

All 4 buttons get equal space.

---

# SECTION 6 — CANVAS (Absolute Positioning)

## THEORY

Canvas uses X/Y coordinates.

No automatic layout.
You manually place elements.

Useful for:
- Drawing tools
- Games
- Precise control overlays

---

## Example

```xml
<Canvas Background="Black">
    <Button Content="Move Me"
            Canvas.Left="50"
            Canvas.Top="30"/>
</Canvas>
```

You can modify position dynamically:

```pwsh
$btn.SetValue([System.Windows.Controls.Canvas]::LeftProperty, 100)
$btn.SetValue([System.Windows.Controls.Canvas]::TopProperty, 50)
```

---

# SECTION 7 — GRIDSPLITTER (Resizable Panels)

## THEORY

GridSplitter allows user to resize grid sections by dragging.

This is the simplest way to create a sliding panel width.

No manual mouse tracking required.

---

## FULL WORKING RESIZABLE SIDEBAR

```pwsh
[xml]$xaml = @"
<Window
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    Title="Resizable Sidebar"
    Width="600"
    Height="350"
    WindowStartupLocation="CenterScreen">

    <Grid>
        <Grid.ColumnDefinitions>
            <ColumnDefinition Width="200"/>
            <ColumnDefinition Width="5"/>
            <ColumnDefinition Width="*"/>
        </Grid.ColumnDefinitions>

        <Border Grid.Column="0" Background="#2C3E50"/>

        <GridSplitter
            Grid.Column="1"
            Width="5"
            HorizontalAlignment="Stretch"
            VerticalAlignment="Stretch"
            Background="Gray"
            ShowsPreview="True"/>

        <Border Grid.Column="2" Background="#34495E"/>

    </Grid>
</Window>
"@

$reader = New-Object System.Xml.XmlNodeReader $xaml
$window = [Windows.Markup.XamlReader]::Load($reader)
$window.ShowDialog() | Out-Null
```

User can now drag to resize sidebar.

---

# SECTION 8 — NESTING PANELS

Panels can be nested infinitely.

Example:

- Grid (Main layout)
  - StackPanel (Sidebar buttons)
  - Grid (Content region)
    - WrapPanel (Dynamic items)

WPF layout is hierarchical.

---

# SUMMARY

Panels define how space is allocated.

Choose panel based on need:

- Complex structured layout → Grid
- Linear stacking → StackPanel
- Edge docking → DockPanel
- Wrapping items → WrapPanel
- Equal cells → UniformGrid
- Absolute positioning → Canvas
- Resizable sections → GridSplitter

Layout mastery is essential for advanced UI like:
- Sliding drawers
- Sidebar navigation
- Dashboard apps
- Resizable panes
- Custom window chrome layouts
