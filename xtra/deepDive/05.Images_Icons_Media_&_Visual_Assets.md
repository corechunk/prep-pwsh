# 📂 File 05 — Images, Icons, Media & Visual Assets

## THEORY

WPF has a powerful visual system built on DirectX.

This allows:

- Raster images (PNG, JPG, BMP, GIF)
- Icons (.ico)
- Vector graphics
- Scaling without quality loss (depending on source)
- Opacity control
- Stretch modes
- Background images
- Image transformations
- Basic media playback (audio/video)

Primary controls:

- `Image`
- `MediaElement`
- `Border` (for background images)
- `Window.Icon`

Images in WPF use `ImageSource` objects internally.

---

# SECTION 1 — BASIC IMAGE CONTROL

## FULL WORKING EXAMPLE

```pwsh
Add-Type -AssemblyName PresentationFramework
Add-Type -AssemblyName PresentationCore
Add-Type -AssemblyName WindowsBase

[xml]$xaml = @"
<Window
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    Title="Image Example"
    Width="500"
    Height="350"
    WindowStartupLocation="CenterScreen">

    <Grid>
        <Image Name="imgMain"
               Source="sample.png"
               Width="200"
               Height="200"
               Stretch="Uniform"
               HorizontalAlignment="Center"
               VerticalAlignment="Center"/>
    </Grid>

</Window>
"@

$reader = New-Object System.Xml.XmlNodeReader $xaml
$window = [Windows.Markup.XamlReader]::Load($reader)

$window.ShowDialog() | Out-Null
```

# SECTION 2 — IMAGE STRETCH MODES

`Stretch` property controls scaling behavior.

Options:

- None
- Fill
- Uniform
- UniformToFill

Example:

```xml
<Image Source="sample.png" Stretch="Fill"/>
```

Behavior summary:

- Fill → stretches to container (may distort)
- Uniform → maintains aspect ratio
- UniformToFill → fills container, may crop

---

# SECTION 3 — LOAD IMAGE DYNAMICALLY (PowerShell)

```pwsh
$img = $window.FindName("imgMain")

$bitmap = New-Object System.Windows.Media.Imaging.BitmapImage
$bitmap.BeginInit()
$bitmap.UriSource = New-Object System.Uri("sample.png", [System.UriKind]::Relative)
$bitmap.EndInit()

$img.Source = $bitmap
```

Works in both PS 5.1 and PS 7.1 (Windows).

# SECTION 4 — BACKGROUND IMAGE

Images can be used as backgrounds.

```xml
<Grid>
    <Grid.Background>
        <ImageBrush ImageSource="background.jpg"
                    Stretch="UniformToFill"/>
    </Grid.Background>
</Grid>
```

Or on Border:

```xml
<Border>
    <Border.Background>
        <ImageBrush ImageSource="background.jpg"/>
    </Border.Background>
</Border>
```

# SECTION 6 — IMAGE WITH TRANSPARENCY

PNG supports transparency automatically.

You can also control opacity:

```xml
<Image Source="sample.png"
       Opacity="0.6"/>
```

Or runtime:

```pwsh
$img.Opacity = 0.5
```

# SECTION 8 — TRANSFORMING IMAGES

WPF supports transforms:

- Rotate
- Scale
- Skew
- Translate

## Rotate Example

```xml
<Image Source="sample.png">
    <Image.RenderTransform>
        <RotateTransform Angle="45"/>
    </Image.RenderTransform>
</Image>
```

Runtime:

```
$rotate = New-Object System.Windows.Media.RotateTransform
$rotate.Angle = 90
$img.RenderTransform = $rotate
```

---

# SECTION 9 — IMAGE ANIMATION

Animate opacity:

```xml
<Image Name="imgFade" Source="sample.png" Opacity="1">
    <Image.Triggers>
        <EventTrigger RoutedEvent="MouseEnter">
            <BeginStoryboard>
                <Storyboard>
                    <DoubleAnimation
                        Storyboard.TargetProperty="Opacity"
                        To="0.3"
                        Duration="0:0:0.3"/>
                </Storyboard>
            </BeginStoryboard>
        </EventTrigger>
    </Image.Triggers>
</Image>
```

# SECTION 10 — MEDIAELEMENT (VIDEO / AUDIO)

WPF can play media.

## Basic Video Player

```xml
<MediaElement Name="mediaPlayer"
              Source="sample.mp4"
              LoadedBehavior="Manual"
              UnloadedBehavior="Stop"
              Width="400"
              Height="250"/>
```

Control playback:

```pwsh
$media = $window.FindName("mediaPlayer")
$media.Play()
$media.Pause()
$media.Stop()
```

Supports:
- **mp4**
- **wmv**
- **mp3**
- **wav**

Depends on system codecs.

---

# SECTION 11 — IMAGE AS PATTERN / TILE

```xml
<ImageBrush ImageSource="pattern.png"
            TileMode="Tile"
            Viewport="0,0,0.2,0.2"
            ViewportUnits="RelativeToBoundingBox"/>
```

Creates repeating pattern.

---

# SECTION 12 — CLIPPING IMAGES

Clip image to shape:

```xml
<Image Source="sample.png">
    <Image.Clip>
        <EllipseGeometry Center="100,100"
                         RadiusX="80"
                         RadiusY="80"/>
    </Image.Clip>
</Image>
```

Produces circular image.

---

# SECTION 13 — HIGH DPI & SCALING NOTES

WPF is DPI-aware.

Vector graphics scale perfectly.
Raster images scale based on resolution.

Best practice:
- Use high resolution PNG
- Use ICO for icons
- Use vector paths for scalable UI graphics
