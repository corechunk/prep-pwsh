# 📂 File 09 — Styling & Templates in WPF + PowerShell

---

# THEORY

Styling in WPF allows you to separate UI appearance from logic. Key points:

1. **Properties:** Background, Foreground, FontSize, FontFamily, BorderBrush, BorderThickness, Opacity.
2. **Images & Icons:** Can be set for Buttons, Windows, and Image controls.
3. **Tooltips:** Provide hover hints.
4. **Top Menu / Context Menu:** Standard menus, can be customized.
5. **Templates:** ControlTemplate, DataTemplate, can redefine visual tree.
6. **Resource Dictionaries:** Reuse styles across multiple controls.
7. **Visual States:** Hover, Pressed, Focused, Disabled.
8. **Rounded Corners / Borders:** Use `CornerRadius` for Border, Buttons.
9. **Transparency & Effects:** Opacity, DropShadowEffect, BlurEffect.

---

# SECTION 1 — BUTTON STYLING

- **Background / Foreground / Font**

```pwsh
$btn.Background = "LightBlue"
$btn.Foreground = "White"
$btn.FontSize = 16
$btn.FontFamily = "Consolas"
$btn.FontWeight = "Bold"
```

- **Border / Corner Radius**

```pwsh
$btn.BorderBrush = "Black"
$btn.BorderThickness = 2
# Wrap in Border for corner radius
$border = New-Object System.Windows.Controls.Border
$border.CornerRadius = [System.Windows.CornerRadius]::new(10)
$border.Child = $btn
```

- **Hover / Pressed Colors (Triggers)**

```pwsh
$style = New-Object System.Windows.Style ([System.Windows.Controls.Button])
$trigger = New-Object System.Windows.Trigger
$trigger.Property = [System.Windows.Controls.Primitives.ButtonBase]::IsMouseOverProperty
$trigger.Value = $true
$trigger.Setters.Add((New-Object System.Windows.Setter([System.Windows.Controls.Control]::BackgroundProperty,"Yellow")))
$style.Triggers.Add($trigger)
$btn.Style = $style
```

# SECTION 2 — IMAGES & ICONS


# SECTION 6 — MENU BAR

- **Menu Creation**

```pwsh
$menu = New-Object System.Windows.Controls.Menu
$fileMenu = New-Object System.Windows.Controls.MenuItem
$fileMenu.Header = "File"
$menu.Items.Add($fileMenu)

$exitItem = New-Object System.Windows.Controls.MenuItem
$exitItem.Header = "Exit"
$exitItem.Add_Click({ $window.Close() })
$fileMenu.Items.Add($exitItem)

$window.Content = $menu
```

- **Context Menu**

```pwsh
$ctx = New-Object System.Windows.Controls.ContextMenu
$menuItem = New-Object System.Windows.Controls.MenuItem
$menuItem.Header = "Option 1"
$menuItem.Add_Click({ Write-Host "Option 1 clicked" })
$ctx.Items.Add($menuItem)

$btn.ContextMenu = $ctx
```

# SECTION 7 — IMAGES & RESOURCES

- **Image Control**

```pwsh
$img = New-Object System.Windows.Controls.Image
$img.Source = [System.Windows.Media.Imaging.BitmapImage]::new((New-Object System.Uri("C:\image.png")))
$grid.Children.Add($img)
```

- **Resource Dictionary Example**

```
$rd = New-Object System.Windows.ResourceDictionary
$style = New-Object System.Windows.Style ([System.Windows.Controls.Button])
$style.Setters.Add((New-Object System.Windows.Setter([System.Windows.Controls.Control]::BackgroundProperty,"LightCoral")))
$rd.Add("RedButton", $style)

$btn.Style = $rd["RedButton"]
```

# SECTION 8 — SLIDING PANEL (Mouse-Resize)

- **Conceptual**

1. Use `GridSplitter` for adjustable panels.
2. Mouse drag changes width/height.
3. Works in WPF+PowerShell.

```pwsh
$grid = New-Object System.Windows.Controls.Grid
$grid.ColumnDefinitions.Add((New-Object System.Windows.Controls.ColumnDefinition))
$grid.ColumnDefinitions.Add((New-Object System.Windows.Controls.ColumnDefinition))
$gridSplitter = New-Object System.Windows.Controls.GridSplitter
$gridSplitter.Width = 5
$gridSplitter.HorizontalAlignment = "Right"
$gridSplitter.VerticalAlignment = "Stretch"
$gridSplitter.Background = "Gray"

$grid.Children.Add($gridSplitter)
```

- **Note:** Assign left panel and right panel to columns, then user can drag splitter.

# SECTION 9 — ADVANCED STYLING

- **DropShadowEffect**

```pwsh
$shadow = New-Object System.Windows.Media.Effects.DropShadowEffect
$shadow.BlurRadius = 10
$shadow.Color = "Black"
$btn.Effect = $shadow
```

- **BlurEffect**

```pwsh
$blur = New-Object System.Windows.Media.Effects.BlurEffect
$blur.Radius = 5
$img.Effect = $blur
```

- **Opacity Mask**

```pwsh
$btn.OpacityMask = [System.Windows.Media.Brushes]::Red
```

# SECTION 10 — SUMMARY

- WPF+PowerShell allows almost all styling and templating available in full WPF.
- Buttons, TextBoxes, Panels, Windows can be styled.
- Images/icons can be set dynamically.
- Tooltips provide hover hints.
- Top menu bar and context menus are fully supported.
- Resource dictionaries and templates enable reusable styling.
- GridSplitter allows sliding/adjustable panels with mouse.
- Effects like Shadow, Blur, Opacity mask add richness to UI.
